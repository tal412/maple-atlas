Connection help & offline use

First, the phone scans the computer’s QR. Then the computer scans the new response shown on the phone. Both screens must say Connected before tracking starts.

If the computer has no camera, use a QR image or copy the phone response using a transfer method you already trust.

Both devices must be on the same reachable local network. A phone on cellular data or a computer on a different network cannot connect through this server-free mode. Guest Wi-Fi, VPNs and firewalls can also block it. Keep both pages open.

Allow camera access on both devices. Browsers keep a device’s local network address private until the page has camera access; without it, the devices exchange private names that many phones and routers cannot resolve. The camera only reads pairing codes. On a Mac, also check System Settings → Privacy & Security → Local Network and make sure your browser is allowed.

The first download needs internet. Saved map data and visual matching can then run locally. Market updates still need internet.
